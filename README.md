# Takeaway application

This is a backend service for a takeaway app built with Spring Boot. It contains REST Apis for both the management end of the restaurant and the user end.



**Restaurant management end functions:**

- Restaurant status management
- Create/Delete dish category
- Add/Delete dish
- Add/Delete setmeal
- Upload picture
- Employee Management
- Order Management
- Generating sales data report
- An overview dashboard



**User end functions:**

- Browse dishes/setmeal

- Browse dishes by category

- Add dishes/setmeal to cart

- Payment ( mockup )

- Delivery address management

- Order Management
